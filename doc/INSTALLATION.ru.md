# Установка репозитория из GitHub

Это руководство описывает, как установить репозиторий Seranov's Kodi Repository напрямую из GitHub.

## Предварительные требования

- Kodi 19.x (Matrix) или новее
- Подключение к интернету

## Способ 1: Установка через File Manager (Рекомендуется)

Этот способ добавляет репозиторий как источник файлов в Kodi, позволяя вам просматривать и устанавливать аддоны напрямую.

### Предварительная настройка

⚠️ **Важно:** Сначала разрешите установку из неизвестных источников.

1. **Разрешите установку из неизвестных источников:**
   - Откройте Kodi
   - Перейдите в **Настройки** (значок шестеренки)
   - Выберите **Система** → **Дополнения**
   - Включите **Неизвестные источники**
   - Нажмите **Да** в диалоге предупреждения

### Шаги установки

1. **Добавьте репозиторий как источник файлов:**
   - Перейдите в **Настройки** → **Файловый менеджер**
   - Нажмите **Добавить источник**
   - Нажмите **<Нет>**
   - Введите URL: `https://seranov.github.io/seranov-kodi/`
   - Введите имя: `Seranov Repo`
   - Нажмите **OK**

2. **Установите репозиторий:**
   - Перейдите в **Настройки** → **Дополнения** → **Установить из файла zip**
   - Выберите **Seranov Repo**
   - Перейдите в папку `repository.seranov`
   - Выберите `repository.seranov-1.0.0.zip`
   - Дождитесь уведомления "Дополнение установлено"

3. **Установите аддоны:**
   - Перейдите в **Дополнения** → **Установить из репозитория**
   - Выберите **Seranov's Kodi Repository**
   - Выберите категорию (Видео дополнения, Контекстные элементы, Службы)
   - Установите нужные аддоны

### Преимущества установки через URL

✅ **Автоматические обновления** - Kodi будет сам проверять обновления  
✅ **Простота** - Не нужно скачивать файлы вручную  
✅ **Всегда актуально** - Ссылка ведет на последнюю версию  
✅ **Одна точка входа** - Все аддоны доступны из одного репозитория

## Способ 2: Прямая установка через URL

Этот способ позволяет установить репозиторий напрямую из интернета без добавления его как источника файлов.

### Прямая установка ZIP из URL

⚠️ **Важно:** Сначала разрешите установку из неизвестных источников (см. Способ 1 выше).

1. **Установите репозиторий из URL:**
   - Перейдите в **Настройки** → **Дополнения** → **Установить из файла zip**
   - Выберите **<Нет>** или введите путь напрямую
   - Введите URL:
     ```
     https://seranov.github.io/seranov-kodi/repository.seranov/repository.seranov-1.0.0.zip
     ```
   - Нажмите **OK**
   - Дождитесь уведомления "Дополнение установлено"

**URL репозитория (GitHub Pages):**
```
https://seranov.github.io/seranov-kodi/repository.seranov.zip
```

После установки репозитория, все аддоны будут получать автоматические обновления!

## Способ 3: Прямая установка ZIP-файла

Это альтернативный способ, если у вас есть проблемы с онлайн-установкой.

### Шаг 1: Разрешите установку из неизвестных источников

1. Откройте Kodi
2. Перейдите в **Настройки** (значок шестеренки)
3. Выберите **Система** → **Дополнения**
4. Включите **Неизвестные источники**
5. Нажмите **Да** в диалоге предупреждения

### Шаг 2: Скачайте ZIP репозитория

Скачайте последнюю версию репозитория с GitHub Pages:

**Прямая ссылка:**
```
https://seranov.github.io/seranov-kodi/repository.seranov.zip
```

Сохраните файл в доступное место (например, на Рабочий стол или в папку Загрузки).

### Шаг 3: Установите ZIP в Kodi

1. В Kodi перейдите в **Настройки** → **Дополнения**
2. Нажмите **Установить из файла zip**
3. Перейдите к месту, где вы сохранили файл
4. Выберите `repository.seranov-1.0.0.zip`
5. Дождитесь уведомления "Дополнение установлено"

### Шаг 4: Установите аддоны

1. Перейдите в **Настройки** → **Дополнения**
2. Выберите **Установить из репозитория**
3. Найдите и выберите **Seranov's Kodi Repository**
4. Выберите категорию аддонов:
   - **Видео дополнения** - для plugin.video.random.recursive
   - **Контекстные элементы** - для context.screenshots
   - **Службы** - для service плагинов
5. Выберите нужный аддон и нажмите **Установить**

## Способ 4: Установка отдельного аддона без репозитория

Если вам нужен только один конкретный аддон:

1. Скачайте ZIP-файл нужного аддона из [Releases](https://github.com/seranov/seranov-kodi/releases/latest):
   - `plugin.video.random.recursive-1.0.0.zip` - Случайный плеер
   - `context.screenshots-1.0.5.zip` - Всплывающие скриншоты
   - `service.seranov.nfoscanner-1.0.0.zip` - NFO Scanner Service
   - `plugin.video.unified.browser-1.0.0.zip` - Unified Browser

2. Следуйте инструкциям **Способа 3** (Шаги 1-3) для установки ZIP-файла

**⚠️ Важно:** Без установки репозитория вы не получите автоматические обновления аддонов.

## Автоматические обновления

> **✅ Доступно:** Репозиторий опубликован через GitHub Pages и поддерживает автоматические обновления!

После установки репозитория (Способ 1), Kodi будет автоматически проверять обновления всех установленных аддонов.

**URL репозитория:** `https://seranov.github.io/seranov-kodi/`

### Как работают автоматические обновления

1. **Установите репозиторий один раз** используя ZIP-файл
2. **Kodi проверяет обновления** автоматически (обычно каждые 24 часа)
3. **Вы получите уведомление** когда доступны обновления
4. **Установите обновления** одним кликом из меню дополнений

### Ручная проверка обновлений

Для ручной проверки обновлений:
1. Перейдите в меню **Дополнения**
2. Нажмите правой кнопкой на **Seranov's Kodi Repository**
3. Выберите **Проверить обновления**

## Проверка установки

После установки репозитория, проверьте:

1. Перейдите в **Настройки** → **Дополнения**
2. Выберите **Установить из репозитория**
3. Вы должны увидеть **Seranov's Kodi Repository** в списке

## Доступные аддоны в репозитории

После установки репозитория, вы получите доступ к следующим аддонам:

### 🎬 Plugin.video.random.recursive
**Случайное рекурсивное воспроизведение видео**
- Рекурсивное сканирование папок
- Воспроизведение в случайном порядке
- Интеграция с контекстным меню

**Установка:**
- Репозиторий → Видео дополнения → SeraNov Random Recursive Player

### 📷 Context.screenshots
**Всплывающие скриншоты**
- Показ локальных изображений в слайд-шоу
- Поддержка file_id.diz файлов
- Интеграция с контекстным меню

**Установка:**
- Репозиторий → Контекстные элементы → SeraNov Popup Screenshots

### ⚙️ NFO Scanner Service
**Служба автоматического сканирования метаданных**
- service.seranov.nfoscanner - Служба сканирования NFO файлов
- Автоматическое обнаружение изменений в movie.nfo
- Поддержка category.nfo для управления жанрами
- Настраиваемые интервалы сканирования
- Приоритетное сканирование на основе навигации пользователя

**Установка:**
- Репозиторий → Службы → NFO Scanner Service

## Обновление аддонов

### Ручное обновление

Для обновления аддонов до новой версии:

1. Скачайте новую версию ZIP-файла из [Releases](https://github.com/seranov/seranov-kodi/releases)
2. В Kodi: **Настройки** → **Дополнения** → **Установить из файла zip**
3. Выберите новый ZIP-файл
4. Kodi автоматически обновит аддон

**Примечание:** Ваши настройки аддона сохранятся при обновлении.

### Отслеживание обновлений

Чтобы не пропустить новые версии:

1. **⭐ Поставьте Star на GitHub:** [github.com/seranov/seranov-kodi](https://github.com/seranov/seranov-kodi)
2. **📢 Watch → Releases only:** Получайте уведомления о новых релизах
3. **📧 Email-уведомления:** GitHub отправит вам письмо о новом релизе

## Удаление репозитория

Если вам нужно удалить репозиторий:

1. **Настройки** → **Дополнения** → **Мои дополнения**
2. Выберите **Репозитории дополнений**
3. Выберите **Seranov's Kodi Repository**
4. Нажмите **Удалить**

**Примечание:** Установленные аддоны останутся, но не будут получать обновления.

## Устранение неполадок

### Файлы не отображаются в Kodi

**Причина:** Kodi кэширует содержимое источника  
**Решение:** 
- Перезапустите Kodi
- Или удалите источник и добавьте заново

### 404 ошибка при открытии URL

**Причина:** GitHub Pages ещё не развёрнут или URL неверный  
**Решение:** 
- Используйте прямой GitHub Pages URL: `https://seranov.github.io/seranov-kodi/repository.seranov.zip`
- Проверьте подключение к интернету
- Попробуйте снова через несколько минут, если GitHub Pages только что развернули

### Ошибка: "Не удалось установить дополнение"

**Причины и решения:**

1. **Проблема с интернетом**
   - Проверьте подключение к интернету
   - Попробуйте позже

2. **URL недоступен**
   - Убедитесь, что файл ZIP был скачан корректно
   - Попробуйте скачать заново из [Releases](https://github.com/seranov/seranov-kodi/releases)

3. **Неизвестные источники отключены**
   - Включите "Неизвестные источники" в настройках (см. Способ 1, Шаг 1)

4. **Устаревшая версия Kodi**
   - Обновите Kodi до версии 19.x или новее

### Ошибка: "Зависимости не установлены"

Некоторые аддоны требуют дополнительные модули:

**Для context.screenshots:**
- script.module.kodi-six
- script.module.routing

**Решение:**
Kodi обычно устанавливает зависимости автоматически. Если нет:
1. Установите аддон снова
2. Или установите зависимости вручную из официального репозитория Kodi

### Репозиторий не появляется в списке

1. Убедитесь, что установка завершилась успешно (проверьте уведомления)
2. Перезапустите Kodi
3. Проверьте лог Kodi на наличие ошибок:
   - Windows: `%APPDATA%\Kodi\kodi.log`
   - Linux: `~/.kodi/temp/kodi.log`


## Альтернативные способы установки

### Для разработчиков и продвинутых пользователей

#### 1. Клонирование из Git

```bash
git clone https://github.com/seranov/seranov-kodi.git
cd seranov-kodi
python scripts/generate_repo.py
```

Затем скопируйте аддоны из репозитория в папку аддонов Kodi.

#### 2. Использование PowerShell скриптов (Windows)

```powershell
# Клонируйте репозиторий
git clone https://github.com/seranov/seranov-kodi.git
cd seranov-kodi

# Разверните локально
.\scripts\deploy-local.ps1
```

См. [scripts/README.md](../scripts/README.md) для подробностей.
