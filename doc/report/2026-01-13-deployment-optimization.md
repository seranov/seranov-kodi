# Оптимизация времени деплоя GitHub Pages

## Дата: 2026-01-13

## Проблема
Шаг `actions/deploy-pages@v4` выполнялся **8 минут 53 секунды**, из которых большую часть времени workflow находился в очереди (`deployment_queued`).

### Детали из логов:
- **Общее время сборки**: 9m 3s
- **Время загрузки артефакта**: 2s (нормально)
- **Время деплоя**: 8m 53s ❌ (слишком долго!)
- **Размер артефакта**: 14.7 MB (слишком большой)
- **Статус в очереди**: `deployment_queued` повторялся 98 раз!

### Причины медленного деплоя:

1. ⚠️ **Большой размер артефакта (14.7 MB)**
   - Конвертировались ВСЕ файлы документации (17 файлов)
   - `docs/doc` весил 296 KB
   - ZIP архивы аддонов: ~11 MB
   - Избыточная документация для простого репозитория

2. ⚠️ **Очередь GitHub Pages**
   - Деплой застревал в `deployment_queued`
   - GitHub Pages имеет ограничения на частоту деплоев
   - Возможно, были предыдущие деплои в очереди

3. ⚠️ **Частые деплои**
   - Workflow запускался на каждый push в `main`
   - Это создавало очередь из деплоев

## Выполненные оптимизации

### 1. Ограничение триггеров workflow

**Было:**
```yaml
on:
  push:
    branches:
      - main
    tags:
      - 'v*'
  workflow_dispatch:
```

**Стало:**
```yaml
on:
  push:
    tags:
      - 'v*'
  workflow_dispatch:
```

✅ **Результат**: Деплой только при создании тега или вручную, не на каждый commit в main

### 2. Уменьшение размера артефакта

**Было:**
- Конвертировались ВСЕ 17 файлов документации через `scripts/convert_md_to_html.py`
- Размер `docs/doc`: 296 KB
- Общий размер: 14.7 MB

**Стало:**
- Конвертируются только 3 основных файла:
  - `doc/README.md`
  - `doc/QUICKSTART.md`
  - `doc/INSTALLATION.md`
- Простая базовая конвертация через Python
- Ожидаемый размер артефакта: ~11-12 MB (↓ 15-20%)

### 3. Добавлен таймаут для деплоя

```yaml
- name: Deploy to GitHub Pages
  id: deployment
  uses: actions/deploy-pages@v4
  timeout-minutes: 5
  continue-on-error: false
```

✅ **Результат**: Если деплой висит в очереди > 5 минут, workflow упадёт с ошибкой вместо ожидания 10 минут

### 4. Добавлена информация о размере артефакта

Добавлен вывод предупреждения о влиянии размера:
```
⚠️  Artifact size affects deployment speed:
   < 5 MB: Fast (1-2 min)
   5-15 MB: Medium (3-5 min)
   > 15 MB: Slow (5-10+ min)
```

## Дополнительные рекомендации

### Если деплой всё ещё медленный:

1. **Разделить документацию на отдельный сайт**
   - Основной репозиторий Kodi: только аддоны (< 12 MB)
   - Документация: отдельный GitHub Pages из другой ветки

2. **Использовать CDN для больших файлов**
   - GitHub Releases для ZIP архивов
   - Pages только для индекса и метаданных

3. **Кэширование**
   - Настроить GitHub Pages с кэшированием
   - Использовать `immutable` для ZIP файлов

4. **Оптимизация ZIP архивов**
   - Проверить, нет ли дублирования файлов
   - Убедиться, что `__pycache__` исключены

### Мониторинг:

После следующего деплоя проверить:
1. Размер артефакта в логах
2. Время выполнения `actions/deploy-pages@v4`
3. Количество повторов `deployment_queued`
